# GameHaven Plus — статус проекта

## Реализовано и проверено
- [x] Отдельный портал на базе исходного проекта. Исходный сайт и его GitHub-репозиторий не изменялись.
- [x] Первые четыре исходные игры/обложки сохранены в каталоге; у всех 12 игр свои карточки и изображения.
- [x] RU/EN/中文 названия и переключение языка; поиск, категории, сортировка, история и подробности игр.
- [x] Ролевой вход `admin` и `igrok` с серверной проверкой; пароли хранятся в секретах проекта, а не в Git.
- [x] Admin может менять локализованные названия, HTTPS iframe/embed-ссылки и игровые обложки: загрузить файл ИЛИ вставить URL (`https://…` либо `/manus-storage/...`). Игроку API редактирования запрещает изменение этих данных.
- [x] Admin может отдельно управлять двумя рекламными местами (верхний 728×90 и боковой 300×250): URL изображения и необязательный HTTPS URL перехода. Оба места протестированы в браузере; после проверки тестовые рекламные настройки очищены.
- [x] Игрок может лайкать/снимать лайк, а список `igrok` хранится в персональном серверном «Избранном». Административные операции пользователю недоступны.
- [x] Адаптивная тёмная тема с лаймовыми акцентами.
- [x] Последняя проверка: `pnpm test` — 13 тестов успешно; `pnpm check`, `pnpm build` и `git diff --check` успешны.
- [x] Изменения отправляются только в отдельный приватный репозиторий `automarketing1210-lab/gamehaven-plus`.

## Замечания по эксплуатации
- В исходном проекте не было работающих HTML5 embed-ссылок; администратор должен вставить легальную ссылку провайдера для фактического запуска игры.
- Превью проекта доступно в Manus. В активном наборе инструментов нет команды WebDev Publish; production-публикацию можно выполнить через UI проекта после сохранения checkpoint. Превью-ссылка не является постоянным публичным production-доменом.
