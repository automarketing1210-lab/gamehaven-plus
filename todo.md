# GameHaven Plus — задачи и статус

## Готово
- [x] Новый отдельный проект на основе исходного GameHaven; исходная версия и её GitHub-репозиторий не изменены.
- [x] Сохранить первые четыре существующие карточки, их названия и изображения в исходном порядке.
- [x] Добавить 8 игр с собственными названиями, переводами и уникальными обложками; в начальном каталоге 12 уникальных игр/обложек.
- [x] Адаптивный каталог с поиском, категориями, сортировками, популярными играми и историей просмотров.
- [x] Переключение RU / EN / 中文.
- [x] Серверная авторизация `admin` / `igrok`, cookie-сессии и проверка полномочий в tRPC; пароли находятся в серверных секретах проекта, не в исходном коде.
- [x] Администратор может менять русское, английское и китайское названия, iframe-ссылку и загружать JPG/PNG/WebP-обложку (до 5 МБ).
- [x] Игрок может добавлять и удалять игры из собственного избранного; разграничение обеспечивается backend-процедурами.
- [x] Схема хранения для каталога и избранного.
- [x] Адаптивная тёмно-синяя тема с лаймовым акцентом, соответствующая исходному дизайну.
- [x] Тесты учётных данных, разрешений, сохранности исходных карточек и уникальности обложек.

## Перед запуском игр
- [ ] В каталоге исходного сайта не было URL игровых билдов/embed. Поэтому игры показывают карточки и экран-подсказку до тех пор, пока администратор не вставит iframe/embed URL для соответствующей HTML5-игры.
- [ ] Проверить каждую предоставленную iframe-ссылку: некоторые игровые площадки запрещают встраивание. Использовать разрешённый embed URL поставщика.

## После публикации
- [ ] При необходимости привязать собственный домен.
- [ ] Заменить временные пароли на длинные уникальные секреты перед публичным продвижением.
- [ ] Добавить рекламные креативы/сеть вместо демонстрационных блоков рекламного места.
