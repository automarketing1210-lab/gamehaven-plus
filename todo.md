# GameHaven Plus — статус

## Жанры
В боковом меню теперь есть все 15 жанров из примера: Action, Adventure, Arcade, Board, Card, Clicker, Driving, .io, Puzzle, Shooting, Simulation, Sports, Strategy, Trivia и Word. Названия локализованы для русского, английского и китайского интерфейсов; иконки и счётчики сохранены в стиле портала. Список прокручивается на небольших экранах.

Существующие игры распределены по наиболее близким жанрам. Старые значения в базе (`racing`, `shooters`, `puzzles`, `casual`) автоматически сопоставляются с новыми категориями, поэтому сохранённый каталог и пользовательские данные не требуют миграции.

## Проверки
`pnpm test` — 16 тестов успешно; `pnpm check`, `pnpm build` и `git diff --check` — успешно. Проверено отображение списка на desktop и фильтрация по жанру Shooting (показывается Strike Point).

## Дальнейшее наполнение
Некоторые жанры пока без игр и показывают нулевой счётчик. Их можно наполнить после добавления карточек подходящих HTML5-игр. Кнопка Tags и контактная ссылка из референса не являются жанрами и не добавлялись в список.
